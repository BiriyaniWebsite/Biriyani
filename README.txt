DUM & EMBER — BIRYANI WEBSITE CONCEPT

Files:
- index.html: page content
- style.css: responsive design and animations
- script.js: mobile navigation and scroll reveal

Preview:
Open index.html in a browser.

Deploy to Cloudflare Pages:
1. Extract this ZIP.
2. Go to Cloudflare Dashboard > Workers & Pages > Create > Pages (or upload assets).
3. Upload the extracted folder/files as a static site, or push them to a GitHub repository and connect it to Pages.
4. Set the custom domain you want in Pages > Custom domains.

Before publishing:
- This is a fictional concept brand, not the original Mr. Biriyaniwala site.
- Replace sample prices/dishes and hello@example.com with your actual details.
- The images are loaded from Unsplash URLs and need internet access.
- For a production restaurant site, add real contact, ordering, allergen, and location information.
